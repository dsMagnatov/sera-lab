# Sera Lab — Medical Lab

Десктопний перший екран лабораторії Sera Lab на Three.js: процедурні двоввігнуті еритроцити, потік великих і малих клітин, фізика зіткнень Rapier, частинки плазми, холодне контрове світло, глибина різкості, bloom і паралакс.

Композиція інтерфейсу повторює `home.jpg`: наданий SVG-логотип і нова назва зверху зліва, навігація та заголовок зліва, скляна картка показників справа, чотири текстові блоки внизу. Нові англомовні тексти присвячені аналізам крові; заголовок містить 9 слів, нижні блоки — 21, 12, 11 і 17 слів. Значення в картці — ілюстративний зразок. Instrument Serif і Manrope завантажуються локально з `public/fonts/`, поруч збережені ліцензії OFL. Навігація виділяє відповідні інформаційні блоки першого екрана.

При скролі камера центрується на головному еритроциті й трохи віддаляється. Рамка аналізу рухається разом із клітиною, а тексти та UI плавно зменшуються слідом за камерою й залишаються видимими. Інші еритроцити й частинки продовжують рух та фізичні зіткнення. Перший екран зменшується в білій рамці з прямими кутами й однаковими відступами 24 px з усіх боків. Далі відкривається каталог аналізів на білому фоні. Зворотний скрол відновлює початковий масштаб. Коли 3D-сцена повністю поза кадром, її рендер призупиняється.

## Запуск

Потрібен Node.js 22.12+ або 24+. У папці проєкту:

```sh
pnpm install
pnpm dev
```

Якщо залежності вже встановлені, можна запустити без глобального pnpm:

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174
```

Відкрити локальну адресу, яку показує Vite. Для стабільного порту 5174 додати `--strictPort`.

## Панель

- **Еритроцит:** геометрія, двобічна западина, випуклість, нерівність краю, орієнтація, колір, процедурна текстура, шорсткість і відблиски.
- **Рух:** кількість, швидкість, завихрення та обертання великих клітин; незалежне керування малими клітинами та частинками плазми.
- **Заповнення країв** підтримує потік у всіх чотирьох частинах кадру, зокрема праворуч зверху та знизу. **Хаотичність траєкторій** додає незалежне бічне коливання і різницю швидкостей. Частина клітин залишається в центральному потоці для зіткнень; після проходження центру клітини розходяться до країв.
- **Фізика зіткнень** у вкладці «Рух»: пружність, тертя, опір плазми, удари об головну клітину, її інерція, швидкість повернення та затухання. Центральна клітина спокійна до зіткнення: від удару зміщується й нахиляється, потім плавно повертається до заданої позиції та орієнтації. Інші клітини наближаються до камери й передають імпульс одна одній. З глибини вони плавно набирають розмір; повернення в потік відбувається після проходження за камеру.
- **Сила реакції на удар** підсилює фактичний імпульс і обертання від контакту. **Частота влучань** керує часткою клітин у спрямованому потоці; після зіткнення вони продовжують вільний рух.
- **Аналіз:** тривимірна рамка перед еритроцитом, яка повторює його позицію, масштаб і нахил. Ближчі до камери клітини перекривають рамку, маркери й цифри за реальною глибиною. Верхня та нижня шкали мають великі й дрібні поділки. Computer Vision-анімація містить рухомі квадрати, декоративні числові координати, зв’язки між маркерами та лінію сканування. Колір рамки, колір цифр, колір і непрозорість їхнього фону, розмір, поділки, швидкість та кількість маркерів налаштовуються окремо.
- **Світло:** колір, інтенсивність і XYZ-позиція трьох джерел; фонове освітлення та світіння простору.
- **Камера:** фокус, розфокусування, боке, перспектива, паралакс, серпанок, експозиція та постобробка. **Паралакс від миші** задає амплітуду від 0 до 30. **Плавність паралаксу** окремо керує часом згладжування від 0 до 5 секунд: більше значення дає повільніший і м’якший рух, 0 — миттєву реакцію. Початкове згладжування — 0,8 с. Цей параметр також записується у файл проєкту.

Чотири пресети, зокрема «Один еритроцит». Значення можна задавати повзунком або вводити числом. Панель локального Vite автоматично записує параметри у `public/bloodstream-settings.json`. Статус «Збережено в проєкті» підтверджує запис. Під час першого відкриття за тією самою адресою панель переносить попередні налаштування з браузера, якщо файл проєкту ще порожній. Якщо налаштування були зроблені за іншою адресою, їх можна перенести через експорт та імпорт JSON. Кнопка камери зберігає PNG самої 3D-сцени, без HTML-інтерфейсу. Панель початково прихована; `H` відкриває її поверх сайту.

`H` приховує або відкриває панель. `Пробіл` призупиняє анімацію, коли фокус поза елементами керування. Миша над сценою керує м’яким паралаксом.

## Збірка

```sh
pnpm check
pnpm test
pnpm build
pnpm preview
```

Для передачі замовнику дочекайтеся статусу «Збережено в проєкті» й запустіть `pnpm build`. Збірка в `dist/` використовує збережені параметри та відкривається без панелі. Для показу потрібен HTTP-сервер, а не відкриття HTML через `file://`.

## Структура

- `src/geometry.js` — замкнена процедурна модель та шейдер мембрани.
- `src/hero.js` — навігація першого екрана та декоративний спектр у картці зразка.
- `src/scroll.js` — віддалення камери, масштабування UI та поява білої рамки.
- `src/scene.js` — Three.js, інстансинг, потік, частинки й постобробка.
- `src/physics.js` — Rapier, нульова гравітація, дископодібні опуклі колайдери, CCD та фіксований крок з інтерполяцією.
- `src/flow.js` — розподіл траєкторій по кадру з урахуванням перспективи та хаотичного руху.
- `src/vision.js` — рамка і Computer Vision-анімація у просторі клітини; чіткий рендер після ефектів об’єктива.
- `tests/physics.test.js` — передавання імпульсу, обертання від ударів, спокій і повернення головної клітини, CCD, плавне повернення в потік та незалежність від FPS.
- `tests/scroll.test.js` — порядок скрол-етапів, масштабування UI, плавність і відновлення при скролі вгору.
- `src/settings.js` — початкові параметри та пресети.
- `src/panel.js` — панель, збереження, імпорт і експорт.
- `src/styles.css` — десктопна панель; мобільні макети не реалізовані.

Референсні JPG залишені у корені. Сцена генерує моделі та текстури процедурно й не використовує ці зображення як тло. Матеріал і просвічування стилізовані для візуального ефекту.
